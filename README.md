## 一、 项目背景与前因 (Project Background)

在传统的中药炮制教学中，**"炒制火候"**的掌握一直是教学的重难点。传统的实训面临以下痛点：
1. **经验数字化难度大**：古籍中记载的"麸下烟起"、"投药时机"高度依赖感官经验，学生难以量化理解。
2. **教学成本与风险高**：大生产用的电磁多功能炒药机造价昂贵，学生初次上手易发生烫伤、烧锅或设备损毁。
3. **评价体系主观**：实训教师难以实时监测每一位学生在数控面板上的参数逻辑是否符合 GMP 规范。

**本系统旨在通过 Web3D 与数字化仿真技术，将传统炮制经验转化为"人机同步"的数字化教学场景，对齐《中药炮制工（国家职业技能标准）》四级标准。**

---

## 二、 核心理论支撑 (Theoretical Framework)

本系统的设计并非简单的 UI 模拟，而是深度融合了以下教育技术理论：
* **境脉学习理论 (Contextual Learning)**：还原中药饮片厂真实生产境脉，将学生置于"中控室操作员"的职业角色中。
* **课证融通 (Qualification Integration)**：所有评分逻辑、操作时机均 1:1 还原《中药炮制工》职业技能鉴定的倒扣分准则。
* **任务驱动法 (Task-Driven)**：将炮制流程拆解为环境核查、参数预设、动态捕捉、应急处理四大任务。

---

## 三、 功能实现细节 (Implementation Details)

系统通过五大核心模块，实现从"手工匠人"到"数字化药工"的技能迁移：

### 1. GMP 合规性前置核查
* **流程**：系统启动前强制弹出巡检窗口。
* **细节**：学生必须勾选"通风系统启动"、"设备已清洁标牌"、"个人防护到位"。
* **考核**：漏选或错选将直接记录入过程性评价，影响素养分。

### 2. 数字化工艺参数设定
* **动态控制**：学生需针对特定药材（如：麸炒枳壳、炒焦栀子）设定**目标温度 (℃)** 与 **滚筒转速 (r/min)**。
* **业务逻辑**：参数设定需符合 GAP 生产标准，过高或过低的参数将导致后续模拟出现"焦炭化"或"受热不均"的负面判定。

### 3. 传统经验数字化："麸下烟起" QTE 系统
* **实时监测**：集成 ECharts 动态曲线，实时模拟炒药机升温热力学模型。
* **瞬时交互 (Quick Time Event)**：
    * **触发点**：当模拟温度到达 180°C - 220°C 窗口期，系统触发"烟雾动画"与"滤镜预警"。
    * **时机判定**：学生必须在 5 秒黄金窗口期内执行【虚拟投药】。提前或延后均会被判定为"火候失控"。

### 4. 异常处理与安全红线 (One-Strike-Out)
* **随机预警**：模拟大生产中常见的"电机过载"或"温控失效"。
* **考核**：学生必须在 3 秒内按下【红色紧急停止】按钮。未能触发安全响应将导致本项目考核"一票否决（0分）"。

### 5. 数字化评价与报告导出
* **逻辑**：后台实时监听 `scoreState` 状态机。
* **成果**：自动生成包含工艺参数、操作延时、得分明细的 JSON/CSV 考核报告，实现教学评价的客观化、数字化。

## 四、 技术架构 (Tech Stack)

* **Frontend**: 原生 JavaScript + Tailwind CSS CDN
* **Visualization**: ECharts.js (用于升温曲线实时渲染)
* **State Management**: 基于状态机逻辑的响应式评分引擎 (8 阶段状态流转)
* **Styling**: 工业化中控面板 UI 设计 (Cyber-Industrial Style)

## 五、 快速开始 (Quick Start)

1. **克隆仓库**
   ```bash
   git clone https://github.com/Leoliny87/tcm-stir-fry-simulator.git
   cd tcm-stir-fry-simulator
   ```

2. **本地运行**

   方式一：Python 快速服务器
   ```bash
   python -m http.server 8080
   ```

   方式二：VS Code Live Server 插件直接打开 `index.html`

   方式三：Node.js 服务器
   ```bash
   npx serve .
   ```

3. **访问**：打开浏览器访问 `http://localhost:8080`

### 运行环境
本系统支持 Chrome/Edge 最新浏览器，建议在手机端/Pad 端运行以获得最佳的仪表盘交互体验。

## 八、 评分体系概览

| 考核项 | 扣分规则 | 分值 |
|--------|---------|------|
| GMP 安全确认 | 跳过确认（未完成巡检） | -5 |
| GMP 安全确认 | 未确认即启动 | -20 |
| 参数设定 | 目标温度/转速超出工艺标准 | -10 |
| 投药时机 | 火候未到提前投药（<180℃） | -15 |
| 投药时机 | 超时未投药（5秒窗口期外） | -10 |
| 投药时机 | 温度超过220℃仍未投药 | -10 |
| 应急处理 | 故障3秒内未拍急停 | -100（一票否决） |
| 清场流程 | 清场顺序错误 | -5/次 |
| 转速异常 | 转速过低导致受热不均 | -5 |
| 温度异常 | 目标温度过高导致焦化 | -10 |

初始分 **100 分**，按倒扣分逻辑累计，最低 **0 分**。
